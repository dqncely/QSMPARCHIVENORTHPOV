# Interpretations & Theories

Your own reads, guesses, and speculation about canon — clearly separated
from confirmed fact. This is the one folder in the "reference" half of the
project where invention is expected; it just has to be labeled as such.

## Rules for this folder

- Every file must open with the label block from the template, stating
  plainly that it is a theory/interpretation, not fact. This label must
  travel with the text — don't rely on the folder location alone, since
  files get copied, quoted, or moved elsewhere later.
- Link back to the canon material (timeline entries, transcripts, character
  sheets) the theory is built on, so it's clear what's fact vs. extrapolation.
- It's fine for theories to be later confirmed or debunked — update the
  **Confidence** field rather than deleting history; note what changed and
  when.

## Template

Copy [`_template-theory.md`](_template-theory.md) for each new
theory/interpretation.
