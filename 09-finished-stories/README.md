# Finished Stories

Completed, polished stories that have graduated from
[`08-prose-drafts/`](../08-prose-drafts). Treat these as done — further
edits should be meaningful revisions, not routine drafting.

## Rules for this folder

- One file per finished story.
- Note the canon-divergence status up top, same as in drafts/outlines, so
  it's clear at a glance whether this is canon-consistent or an AU.
- Keep a link back to the outline/draft it came from, for provenance.

## Template

Copy [`_template-story.md`](_template-story.md) for each finished story.
