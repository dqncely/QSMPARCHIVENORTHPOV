# Relationship Sheets

Reference sheets for the dynamic *between* two (or more) characters —
canon facts only. Your own reads on subtext, ship theories, or predicted
arcs belong in
[`06-interpretations-theories/`](../06-interpretations-theories), linked
from the relevant relationship sheet.

## Rules for this folder

- One file per relationship/dynamic. Name it
  `character-a-and-character-b.md` (alphabetical order for consistency).
- For group dynamics (a whole faction's internal relationships), it's fine
  to have one file covering the group — use judgment.
- Canon facts must cite a **Source**.
- Keep "what's been shown/said on stream" separate from "what I think it
  means" — the latter goes in interpretations, not here.

## Template

Copy [`_template-relationship.md`](_template-relationship.md) for each new
relationship sheet.
