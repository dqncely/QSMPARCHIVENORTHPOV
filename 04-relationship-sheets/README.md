# Relationship Sheets

Reference sheets for the dynamic *between* two (or more) characters —
canon facts only. Your own reads on subtext, ship theories, or predicted
arcs belong in
[`06-interpretations-theories/`](../06-interpretations-theories), linked
from the relevant relationship sheet.

## Rules for this folder

- One file per relationship/dynamic. Name it
  `character-a-and-character-b.md` (alphabetical order for consistency).
- For group dynamics (a whole faction's internal relationships), it's fine
  to have one file covering the group — use judgment.
- Relationships are tracked **over time, not as a static description** —
  most sections are tables keyed to Event IDs from
  [`../01-canon-timeline/`](../01-canon-timeline), so the state at any
  point is reconstructable instead of flattened into one summary. Add new
  rows as the relationship develops; don't overwrite history.
- Canon facts must cite a **Source**; every claim carries a tag from
  [`../CERTAINTY-LEVELS.md`](../CERTAINTY-LEVELS.md).
- Plot-relevant shared secrets/revelations link to
  [`../11-continuity-tracking/`](../11-continuity-tracking) (Revelation
  IDs) rather than being re-described here — this folder tracks the
  *relationship*, that folder tracks *who knows what*.

## Template

Copy [`_template-relationship.md`](_template-relationship.md) for each new
relationship sheet.
