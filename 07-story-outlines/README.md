# Story Outlines

Outlines and beat sheets for original stories, planned before drafting.
Fiction here may draw on canon, interpretation, or deliberately diverge from
canon — just note which when it matters (see
[PROJECT_RULES.md](../PROJECT_RULES.md) rule 5).

## Rules for this folder

- One file per story/outline.
- Note whether the story stays consistent with canon or is an intentional
  AU/divergence, and from what point.
- Link to relevant character/relationship/faction sheets and any theories
  the story is building on.

## Template

Copy [`_template-outline.md`](_template-outline.md) for each new outline.
