# QSMP 2 — Writing Project

A personal archive and writing workspace for fan fiction / creative work set in
the QSMP 2 continuity. This repo keeps **canon reference material** strictly
separate from **personal interpretation, theory, and original fiction**, so
it's always clear what's "fact" and what's invention.

See [PROJECT_RULES.md](PROJECT_RULES.md) for the full rules on canon vs.
theory vs. fiction — read that before adding content.

## Folder structure

| Folder | Purpose |
|---|---|
| [`01-canon-timeline/`](01-canon-timeline) | Dated, sourced list of events that actually happened in-canon. |
| [`02-transcripts/`](02-transcripts) | Raw/verbatim transcripts of streams, VODs, or other primary sources. Ground truth. |
| [`03-character-sheets/`](03-character-sheets) | Reference sheets for individual characters (canon facts only). |
| [`04-relationship-sheets/`](04-relationship-sheets) | Reference sheets for relationships/dynamics between characters (canon facts only). |
| [`05-worldbuilding-factions/`](05-worldbuilding-factions) | Locations, factions, lore, and world mechanics (canon facts only). |
| [`06-interpretations-theories/`](06-interpretations-theories) | Your own theories, reads, and speculation — clearly separated from canon. |
| [`07-story-outlines/`](07-story-outlines) | Outlines/beat sheets for original stories, planned before drafting. |
| [`08-prose-drafts/`](08-prose-drafts) | Work-in-progress prose. Messy is fine here. |
| [`09-finished-stories/`](09-finished-stories) | Completed, polished stories. |
| [`10-images-design-refs/`](10-images-design-refs) | Character art, maps, mood boards, and other visual references. |
| [`11-continuity-tracking/`](11-continuity-tracking) | Master "who knows what, since when" tracker — revelations, false beliefs, and who's told whom, shared across all characters. |

Each folder has its own `README.md` explaining what belongs there, and most
have a `_template.md` to copy when adding a new entry.

## Status

Structure, templates, and rules only — no QSMP information has been added
yet. This repo starts empty on purpose; canon content gets added deliberately
and with sourcing, per [PROJECT_RULES.md](PROJECT_RULES.md).

## Conventions

- Everything is Markdown (`.md`) so it's readable and editable by hand,
  in any editor, with no tooling required.
- File names use `kebab-case.md`.
- Every canon-facing file (timeline, transcripts, character/relationship/
  worldbuilding sheets) carries a **Source** field. No source, no entry.
- Every interpretation/theory file is clearly labeled as non-canon in its
  own content, not just by folder location — files get moved and context
  gets lost, so the label should travel with the text.
