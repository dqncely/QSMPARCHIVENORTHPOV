# Images & Design References

Character art, maps, mood boards, and other visual references. Not
Markdown by nature, but every image should be logged in
[`INDEX.md`](INDEX.md) with a description and source, so the folder stays
searchable and sourced like everything else.

## Rules for this folder

- Add an entry to `INDEX.md` for every image you add: file name,
  description, and source (artist/creator, link, or "official" / "fan art"
  / "reference photo" etc. plus any usage caveats).
- Keep original file names where practical, or rename to
  `kebab-case` and note the original name in the index.
- Don't treat fan art or AI-generated images as canon appearance
  references unless explicitly noted — see
  [PROJECT_RULES.md](../PROJECT_RULES.md).

## Template

Copy the entry format at the bottom of [`INDEX.md`](INDEX.md) for each new
image.
