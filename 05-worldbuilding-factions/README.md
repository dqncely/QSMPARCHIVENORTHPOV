# Worldbuilding & Factions

Reference material on locations, factions, groups, and world mechanics —
canon facts only. Your own extrapolations about how the world works, faction
politics theories, etc. belong in
[`06-interpretations-theories/`](../06-interpretations-theories), linked
from the relevant entry here.

## Rules for this folder

- One file per faction, location, or distinct world-mechanic topic.
- Canon facts must cite a **Source**.
- Keep confirmed rules/lore separate from guesses about how things work —
  guesses go in interpretations, not here.

## Templates

- Copy [`_template-faction.md`](_template-faction.md) for a faction/group.
- Copy [`_template-location.md`](_template-location.md) for a place.
