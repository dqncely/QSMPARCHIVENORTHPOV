# Prose Drafts

Work-in-progress prose. Messy is fine here — this is a drafting space, not a
showcase. Completed, polished pieces move to
[`09-finished-stories/`](../09-finished-stories) when ready.

## Rules for this folder

- One file per draft, matching its outline in
  [`07-story-outlines/`](../07-story-outlines) where one exists.
- Keep the **Status** field current (Draft / Revising / Ready to finalize).
- Drafts-in-progress that are being actively worked on can live in
  [`wip/`](wip); once a draft is stable/complete, it graduates to
  `09-finished-stories/` (or stays here if it's staying unfinished/shelved).

## Template

Copy [`_template-draft.md`](_template-draft.md) for each new draft.
